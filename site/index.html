Request check consistency set

A reproducible QA set that sends 20 fixed documentation examples and labeled variants to the IMD free request evaluator five times each. The sequential runner makes 100 calls with at least three seconds between starts.

Run it with Node.js 20 or newer using npm run check. The script uses built-in fetch and records raw replies, verdicts, agreement rates, and blocker flips.
